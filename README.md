# 🌍 My World

A minimal travel tracker for my journey to visit every country in the world.

My goal: **visit all 195 countries.**

## Features

🌎 Interactive world map
🟢 Visited countries tracking
✈️ Next destinations based on travel budget
📊 Progress towards 195 countries
💰 Affordable trip planning for future adventures

## Tech Stack

* React
* TypeScript
* Vite
* SVG Map
* GeoJSON / TopoJSON
* CSS

## About

A personal project to visualize my journey around the world, track the countries I have already visited, and plan the next destinations on my list.

The idea is to make exploring the world feel achievable: instead of thinking about all 195 countries at once, focus on the next adventure and move forward one country at a time.
